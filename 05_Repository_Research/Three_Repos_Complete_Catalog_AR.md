# الفهرس المستقل للمستودعات الثلاثة

**تاريخ مراجعة الفهارس:** 9 نوفمبر 2026. القائمة مبنية على ملفات README والتوثيق الرسمي وفهرس النماذج وقت المراجعة.

**حدود الشمول:** يغطي هذا الملف جميع بنود الفهرس المنشور في Awesome LLM Apps (122 مدخلًا)، ومكوّنات Langflow الأساسية الموثقة وحزم مزودي الخدمة والقديمة، والتكاملات المذكورة في README الخاصة بـ Ollama، وعائلات النماذج الـ268 الظاهرة في مكتبتها وقت المراجعة. هذا ليس جردًا لكل ملف برمجي أو جميع المكوّنات الفرعية داخل كل حزمة؛ هذه قد تختلف بحسب إصدار التثبيت. بعض البنود مكررة تحت وظائف مختلفة وبعضها خارجي وليس جزءًا من المستودع نفسه.

**طريقة استخدام بند:** افتح رابطه ← اقرأ README أو Docs الخاصة به ← راجع المتطلبات وطرق التشغيل والترخيص، وما إذا كان محليًا أو سحابيًا. ظهور بند في فهرس لا يثبت أنه يعمل فورًا أو أن تشغيله مجاني. المستودع الأول تحت Apache-2.0، وLangflow بحسب مستودعه تحت MIT؛ مكوّنات الجهات الخارجية والنماذج لها تراخيص وشروط مستقلة.
