# Unified AI Personal — المتطلبات والقرارات

هذا المستودع مخصص لمتطلبات وتصميم تطبيق واحد، وليس لتشغيل تطبيق ويب أو نواة مستقلة.

الشيفرة التنفيذية للتطبيق الأصلي على iPhone والخادم في [yjtjcfc5cm-boop](https://github.com/as1411307-collab/yjtjcfc5cm-boop).

الفروع التاريخية التي تحمل دراسات وفهارس مطولة ليست مكونات بناء ولا تُستورد إلى التطبيق تلقائيًا. تُحفظ للاسترجاع التاريخي، ولا تُعتبر مواصفات معتمدة قبل مراجعتها مقابل متطلبات المنتج الحالية.
